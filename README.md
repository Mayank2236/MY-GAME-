# 🎮 Tetris Game

A classic Tetris game built using **HTML, CSS, and JavaScript**. The player controls falling blocks, arranges them to complete horizontal lines, and earns points.

## 🚀 Features

- Colorful falling blocks
- Move blocks left and right
- Rotate blocks
- Move blocks down faster
- Clear completed rows to earn points
- Live score display
- Game Over detection
- Restart button
- Simple and responsive user interface

## 🛠️ Technologies Used

- **HTML5** – Creates the structure of the game.
- **CSS3** – Styles the game board, buttons, and layout.
- **JavaScript** – Controls game logic, movement, collision detection, and scoring.
- **HTML Canvas** – Displays the game board and blocks.

## 🎯 How to Play

1. Open the game in your web browser.
2. Click the **Start Game** button.
3. Use the keyboard to control the falling blocks.

| Key | Action |
|---|---|
| ← Left Arrow | Move left |
| → Right Arrow | Move right |
| ↑ Up Arrow | Rotate the block |
| ↓ Down Arrow | Move down faster |
| Spacebar | Drop the block instantly |

Complete horizontal rows to clear them and increase your score. The game ends when the blocks reach the top of the board.

## 💻 How to Run Locally

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your web browser.
4. Click **Start Game** and enjoy!

No additional libraries or installations are required.
